# 🌌 Nebula AI Support Hub

MVP внутрішньої системи інструментів для команди підтримки Nebula. Проєкт складається з двох модулів: AI-класифікатора звернень та AI-асистента (Copilot) для агентів.

## 🏗 Архітектура та Технічний Стек

- **Бекенд:** FastAPI (єдина точка входу для обох сервісів).
- **AI Інтеграція:** OpenRouter API (використано моделі Meta Llama 3.3 / Gemini 2.0 Flash) + бібліотека `instructor`.
- **Фронтенд:** Streamlit.

**Архітектурне рішення: Чому Streamlit, а не Next.js/React?**
Оскільки завдання полягає у створенні внутрішнього інструменту (internal tool) для Support-відділу, ключовими факторами є Time-to-Market та гнучкість ітерацій. Streamlit — це індустріальний стандарт для швидкого прототипування AI-інструментів. Це дозволило мені зосередитися на AI-логіці, обробці крайніх випадків (edge cases) та надійності, уникнувши оверінжинірингу на стороні клієнтського UI.

**Архітектурне рішення: Чому моноліт, а не мікросервіси?**
Для MVP поділ на мікросервіси є надлишковим. Обидва таски ділять спільну інфраструктуру (FastAPI, Pydantic-схеми, виклики до LLM). Проте код логічно розділений на рівні папок (`services/classifier.py` та `services/copilot.py`), що дозволить легко винести їх в окремі сервіси при зростанні навантаження.

## 🚀 Як запустити локально

1. Створіть та активуйте віртуальне середовище:
```bash
python3 -m venv venv
source venv/bin/activate
```
2. Встановіть залежності:
```Bash
pip install -r backend/requirements.txt
pip install -r frontend/requirements.txt
```
3. Створіть файл .env у корені проєкту та додайте свій ключ:
```bash
OPENROUTER_API_KEY=ваш_ключ
```
4. Запустіть бекенд (Термінал 1):
```Bash
python -m uvicorn backend.main:app --reload
```
5. Запустіть фронтенд (Термінал 2):

```Bash
streamlit run frontend/app.py
```
